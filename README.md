# FISHING WORLD 3D · 湖光物语

**状态：可玩原型（Prototype），不是完整商业级或内容成熟的 3D 钓鱼游戏。**

这是面向桌面和触控浏览器的轻休闲 Three.js 钓鱼玩法验证。无需安装、无需帐号、无服务器数据收集。当前页面可试玩，但其玩法深度、角色控制、鱼类 AI、场景多样性和长期内容均未达到完整游戏标准。

## 当前原型已实现的基本游玩闭环
进入世界 → 选择湖区（解锁等级）→ 抛竿 → 观察鱼漂 → 有鱼咬钩时提竿 → 点按/按住收线并控制张力 → 捕获鱼获 → 领取金币和经验 → 购买鱼竿/鱼饵 → 解锁新湖区、收集十种鱼与完成循环任务。存档自动保存在本机浏览器。

### 游戏内容
- 四组水域配置（当前主要沿用同一程序化场景并变更氛围，并非四张完全独立地图）、十种鱼、重量与个人纪录、图鉴。
- 七项可购买/装备的钓具、经济系统、成长等级和循环委托。
- 程序化基础 3D 湖泊、树木、码头、水波、天空、天气效果、抛竿动画、3D 鱼模型和简化的收线对抗。
- 键盘与手机按钮、音效控制、帮助界面、结果反馈与安全存档恢复。
- Node.js 原生逻辑测试，GitHub Actions CI，GitHub Pages 自动发布。

## 本地运行
Node.js 20+：运行 \`npm test\`；运行 \`npm run start\` 并访问 http://localhost:5173。浏览器需有 WebGL2，首次启动需连接 jsDelivr CDN 获取 Three.js。GitHub Pages： https://aincfh.github.io/fishing-world-3d/

## 发布
Settings → Pages → Source：GitHub Actions。每次推送至 main 自动运行测试与发布。仅在部署成功并完成试玩后视为正式上线。

## 权限和素材
所有游戏物体均用程序化几何体生成，未使用第三方商业游戏素材。声音由 Web Audio API 在本地合成；只使用 Three.js 开源依赖。
## 尚未完成 / 不能作为成熟游戏宣传

- 角色尚不能自由在整个 3D 世界行走、登船或沿岸探索；场景深度及碰撞系统不足。
- 鱼类的生态 AI、动态咬钩、目标感知、逃窜路径、真实物理拉力等仍是简化模拟。
- 四组水域目前并非四张分别制作、可自由探索的完整地图。
- 任务、商店和存档是基础闭环，尚未验证长期平衡与内容持续性。
- 现有自动测试以逻辑单元测试为主，不代表画面质量、操作体感、性能或完整通关体验通过。

深度第一人称路线的优先评估候选是 [WILDLANDS](https://github.com/AincFh/wildlands-anglerfishing-world-3d)，该仓库同样属于开发中的可玩原型。两个仓库在完成架构和玩法审查前不会合并或删除。

## 2026-11 · 钓点生态和水深玩法
抛投位置现在参与真实计算，而不仅用于鱼漂显示：半径 16 米以内为深水鱼道，16–30 米为湖底缓坡，30 米以外为芦苇浅滩（禁投区仍无效）。不同鱼类拥有独立栖息地偏好，地形影响等待咬钩时间、鱼种概率以及搏鱼拉力。HUD 显示钓点、水深与提示，水面标记颜色随位置变化；四片水域共用该系统，存档无需迁移。新增自动化逻辑测试；尚需浏览器端实测、CI 验证与更精细的真实鱼群 AI。
